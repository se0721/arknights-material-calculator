# 明日方舟材料转化计算器

纯静态网页，包含加工站养成材料转化与四至六星干员专精材料统计。

- 材料目标仅显示可加工合成的养成材料；原料保留用于计算。
- 支持至紫色、至蓝色和基础原料三个拆分视图。
- 干员支持搜索、星级筛选、头像和专精进度滚轮。
- 专精结果只统计养成材料，不包含技巧概要；合成不计龙门币及随机副产物。

## 数据与图片

游戏数据来自 [Kengxxiao/ArknightsGameData](https://github.com/Kengxxiao/ArknightsGameData)，由浏览器从 GitHub 或 jsDelivr 在线读取。头像来自 [yuanyan3060/ArknightsGameResource](https://github.com/yuanyan3060/ArknightsGameResource)，图片使用 PRTS 资源及备用地址。外部资源不可用时，仅提供有限源岩链备用数据。

这是非官方工具。游戏名称、美术及相关素材权利归各自权利人所有。

打开 index.html，或使用任意静态托管服务。GitHub Pages 发布源为默认分支的根目录。
